TITLE: ⚡ Optimize undoMatchmakerSwipe using Set for O(1) lookups
BODY:
💡 What: Precomputed swiped IDs into a Set before the loop.
🎯 Why: Replaced O(N) Array.includes with O(1) Set.has inside a find loop, preventing an O(N*M) bottleneck.
📊 Measured Improvement: Improved worst-case execution time from 8.98ms to 4.06ms for N=50000 in benchmarks, and improved best-case large scans from 3.22ms to 0.69ms.
