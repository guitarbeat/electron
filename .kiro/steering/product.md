# Product Overview

A collaborative weekend planning application for couples (Aaron & Electra) featuring:

- **Watchlist**: Collaborative movie/show queue management with OMDb integration
- **Places**: Location tracking and planning for date spots
- **Quiz System**: Personality/compatibility quiz with custom editor
- **Matchmaker**: Swipe-based decision making for activities
- **Mini-games**: Food Merge game, Spin Wheel picker
- **Memories**: Photo/memory collection and sharing

The app uses a playful, Y2K-inspired design with floating bubbles, cat avatars, and emoji-heavy UI. Multi-user support allows switching between Aaron and Electra profiles with persistent state.

## Key Features

- Dual-user system with profile switching
- Real-time collaborative planning
- Mobile-responsive with bottom navigation
- Theme switching based on active workspace (movies vs places)
- Gist-based data persistence for memories and metadata
