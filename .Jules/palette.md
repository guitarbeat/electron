## 2026-05-03 - Added ARIA labels to PolaroidMemory actions\n**Learning:** The `PolaroidMemory` component uses heavily styled, absolute-positioned icon-only buttons for core actions (Pin/Delete) that are revealed on hover via CSS. Because these are visually icon-only and rely on the `title` attribute for tooltips, they need explicit `aria-label` attributes to be properly announced by screen readers without relying on standard text content.\n**Action:** Always ensure absolute-positioned or hover-revealed action buttons receive proper `aria-label`s matching their `title` or intended action to maintain accessibility parity with the visual interface.
