## 2024-05-18 - Handling Meta-Issue Tasks\n\nWhen assigned a task based on an item from a guideline document or template (e.g., .agents/skills/.../SKILL.md), be very careful not to "solve" the issue by simply editing the template to mark it complete. These are meant to be active checklists. Always verify if there are any *actual* violations in the source code (e.g., real TODO comments). If there are none, the correct action is a no-op.
